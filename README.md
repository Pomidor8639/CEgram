# CEgram

**CEgram** — нативный автономный клиент Telegram для **Windows CE / Windows Mobile**, работающий напрямую по протоколу **MTProto 2.0 без каких-либо мостов, прокси и промежуточных серверов**.

---

## 🎯 Цели проекта

1. **Автономность:** Прямое подключение к серверам Telegram по TCP (порты 443 / 80 / 25).
2. **Максимальная совместимость:**
   * Pocket PC 2002 / 2003 / Windows Mobile 2003 SE
   * Windows Mobile 5.0 / 6.0 / 6.1 / 6.5 / 6.5.3
   * Windows CE 4.2 / 5.0 / 6.0 (навигаторы, терминалы, КПК)
   * Поддержка архитектур ARM (ARMv4T, ARMv5TE, XScale) и x86.
3. **Легковесность:**
   * Чистый **C (C89/C99)** без внешних тяжёлых зависимостей.
   * Прямое использование Win32 API и Winsock.
   * Потребление памяти в пределах 2–5 МБ (при системном лимите WinCE в 32 МБ).

---

## 🏗 Архитектура

* `include/cegram/` — заголовочные файлы ядра (типы, криптография, MTProto, TL-кодеки).
* `src/core/` — кроссплатформенное ядро (работает одинаково на современном ПК и на WinCE):
  * `transport.c` — сетевой стек (Abridged/Intermediate TCP).
  * `crypto.c` — криптографические примитивы (AES-256 IGE, SHA-1, SHA-256, RSA 2048, Diffie-Hellman).
  * `mtproto.c` — реализация MTProto 2.0 (рукопожатие авторизации, шифрование сессий, message_id).
  * `tl.c` — минималистичный бинарный кодек TL-схем.
* `src/platform/cli/` — консольный клиент для тестирования и отладки ядра на ПК.
* `src/platform/wince/` — нативный GUI для Windows CE на чистом Win32 GDI.

## 🚀 Сборка для ПК (тестирование ядра)

Запустите `build.bat` из папки проекта (требуется установленный Visual Studio 2022 с компонентами C++):
```cmd
build.bat
```
Собранный исполняемый файл появится в `bin/cegram_cli.exe`.
